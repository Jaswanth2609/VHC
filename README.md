# VHC
Hydration coach
OVERVIEW
The Hydration Coach is a comprehensive health and wellness application designed
to help users maintain proper hydration throughout the day. The application
provides both command-line (CLI) and graphical user interface (GUI) options,
making it accessible for different user preferences and use cases.

The application intelligently calculates personalized hydration goals based on
user activity levels, weather conditions, and custom preferences. It sends
timely reminders during working hours and tracks progress with detailed
analytics and visualizations.
